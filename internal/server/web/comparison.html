H2 · Private release decisions

Compare adaptive width with and without the gate. Reusing an estimate adds no release cost, but each new private probe spends budget. Staleness remains part of the accuracy measurement.

H3 · Trust-model trade-offs

Run the H3 experiment to compare HybridSketch with Sampled Count-Min LDP at matched cumulative epsilon every round, across paired seeds, budgets, widths, and drift scenarios. It measures accuracy, processing time, and payload. The live table uses the configured budgets; use the CLI for the matched comparison.
